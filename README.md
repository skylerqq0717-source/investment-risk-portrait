# 风险画像｜投资风格测评

独立的中国证券投资情境互动测评网站。前端由 GitHub Pages 托管，密码验证与匿名结果保存由独立的 Supabase 项目处理。

## 功能

- 20 道题，支持返回上一题并修改答案。
- 5 种画像与动态角色，含生活底盘、心理承受、投资知识和行为观察。
- 结果页支持下载 PNG 长图、复制需密码才能查看的分享链接。
- 适配手机和电脑。

## 部署

仓库根目录的 `index.html` 和 `supabase-config.js` 直接由 GitHub Pages 的 `main` 分支根目录发布。`supabase/schema.sql` 为后端数据库定义；`supabase/set-access-code.template.sql` 仅为项目所有者在 SQL Editor 中设置入口密码的模板，仓库没有真实密码或 Supabase 服务端密钥。

## 使用边界

该测评用于投资者教育和自我观察。趣味画像不等同于证券公司正式风险等级，不可作为开户、产品准入或合规分级依据，不构成投资建议。题目覆盖财务承受能力、风险意愿、经验、知识等维度，但未完成正式信效度检验。
